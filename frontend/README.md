# CurseForge - Student Team Members Management App

A full-stack web application to manage team members, built using the MERN stack.

## 🛠 Tech Stack

- **Frontend:** React.js (React Router, Axios)
- **Backend:** Node.js + Express.js
- **Database:** MongoDB (via Mongoose)
- **File Uploads:** Multer

## 🚀 Features

- Add new team members with image upload
- View all members in a card grid layout
- View detailed profile of each member
- Clean, responsive UI
